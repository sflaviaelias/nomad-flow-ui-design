# 🌍 Go Nomad — Nomad Flow UI

**EN 🇺🇸**  
**Go Nomad** is an AI-powered travel planning application built for digital nomads and long-term travelers.  
It helps users plan, organize, and manage trips in one place — combining automation, intelligent insights, and a modern UI.

This project’s interface was created using the **Lovable** platform, with natural-language prompting powered primarily by **Anthropic’s Claude LLMs** to generate and refine React components, layout, and flow.

**PT-BR 🇧🇷**  
**Go Nomad** é um aplicativo inteligente de planejamento de viagens criado para viajantes e nômades digitais.  
Ele centraliza o planejamento, a organização e a execução de viagens em um único lugar — unindo automação, inteligência artificial e design moderno.

A interface foi desenvolvida com a plataforma **Lovable**, utilizando prompts em linguagem natural e os modelos da **Anthropic (Claude)** para gerar e aprimorar componentes e fluxos em React.

---

## ✨ Product Vision / Visão de Produto

**EN:**  
Go Nomad aims to simplify long-term travel for modern explorers by providing:  
- Trip planning and budgeting by country and currency  
- Automatic currency conversion  
- Smart, AI-driven recommendations for routes, visas, and local insights  
- A clean, elegant interface built with **shadcn-ui** + **Tailwind CSS**

**PT-BR:**  
O Go Nomad busca simplificar a jornada de quem viaja por longos períodos, oferecendo:  
- Planejamento e orçamento por país e moeda local  
- Conversão automática de moeda  
- Recomendações inteligentes sobre roteiros, vistos e informações locais  
- Interface limpa e elegante construída com **shadcn-ui** + **Tailwind CSS**
